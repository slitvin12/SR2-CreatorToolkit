# AGENTS.md

## Проверка в живой игре (Slime Rancher 2 + Creator Toolkit)

В игре стоит мод-компаньон **Agent Director** — локальный HTTP-мост для агента. Проверяйте изменения через него,
а не по догадкам: смотрите состояние и UI, кликайте, снимайте экран с разметкой, считайте ошибки.

- Обёртка: `ct.cmd` в корне (`ct help`). Полная шпаргалка: [AGENT-DIRECTOR.md](AGENT-DIRECTOR.md).
- Начало: `ct status` → `ct launch` → `ct wait ready timeout=180` → `ct errors reset`.
- После правки UI: `ct smoke` (exit 0 — все вкладки открываются, новых ошибок нет), затем `ct shot NAME marks small`
  и посмотрите файл из поля `view`.
- Клики по номерам с размеченного снимка: `ct click 12` (IMGUI id), `ct click c3` (нативная кнопка),
  по метке: `ct click "Спавн"`, по пикселям: `ct click 960,540`.
- Проверка результата: `ct assert noerrors tab=1 "ui=Спавн"` (exit 2 — не прошло, причины в `failures`).
- Коды выхода ct: 0 — ок, 1 — ошибка вызова, 2 — ошибка моста или проверки, 3 — мост недоступен.

## Правила

- Клики, спавн и телепорт требуют `ct optin on`; спавн и телепорт — ещё и тестовый сейв. Не обходите гейты.
- Перед копированием DLL в `Mods` закройте игру (`ct kill`): Windows держит загруженные DLL.
- Не сворачивайте окно игры во время снимков: без отрисовки кадров снимок не запишется.
- Исходники моста — `src\agentdirector`. Сборка: `_work\agentbridge\build-agent.cmd` (Release → `_work\agentdirector-stage`, нужно 0 предупреждений и 0 ошибок), затем скопировать DLL в `<SR2>\Mods` при закрытой игре.
